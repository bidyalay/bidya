## Learning Resources

### 1. Computer Basics
- A computer is an electronic machine that works with data.
- **Input** means giving information to a computer.
- **Output** means getting a result from a computer.
- Input devices include keyboard, mouse, and microphone.
- Output devices include monitor, printer, and speaker.

### 2. Hardware and Software
- **Hardware** is the physical part of a computer that we can touch.
- **Software** is a set of instructions that tells a computer what to do.

### 3. Programming Basics
- A program is a set of instructions for a computer.
- An algorithm is a step-by-step way to solve a problem.
- Three simple ideas are sequence, decision, and repetition.

### 4. Internet Safety
- Keep passwords private.
- Do not share personal information with strangers.
- Think before clicking unknown links.
- Be kind and respectful online.
